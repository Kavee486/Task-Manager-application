# Task Manager

A small full-stack task manager: a **NestJS** REST API (`/api`) and a **Next.js + shadcn/ui** frontend (`/web`).

> Work in progress — the full setup guide, API reference and "How I used AI" section will be completed in the final step.

## Structure

| Folder | Description |
| ------ | ----------- |
| `api/` | NestJS backend (REST API) |
| `web/` | Next.js frontend (App Router + shadcn/ui) |

## Prerequisites

- Node.js 20+ (developed on Node 24)
- npm 10+
